# 上海·夜 Shanghai Night

黄浦江夜色为底、外滩金为印、霓虹粉紫点缀的深色主题。壁纸：陆家嘴与浦东夜色。

![preview](preview.png)

## 安装

```bash
omarchy theme install https://github.com/rwanglq-ctrl/omarchy-shanghai-night-theme
```
